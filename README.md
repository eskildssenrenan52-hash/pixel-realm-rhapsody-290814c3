# Pixel Realm Rhapsody

https://github.com/eskildssenrenan52-hash/pixel-realm-rhapsody traga o conteúdo do repositório e adicione vários modos de jogo novos no jogo como torre babel, partida rápida etc, refine bastante esses sistemas e faça cada detalhe ser feito com IA geradora de imagens em pixel art mantendo o estilo do jogo. Faça também cada robô ter 10 ataques e 5 defesas, cada um diferente do outro, cada robô com ataques e efeitos difererentes, mas só pode selecionar 4 para jogar na partida no cartão dele na tela de seleção de robôs
